# Planet conversion

The runtime files are already included. You only need Python if you change how the planets are made.

```sh
python3 -m venv .venv
.venv/bin/pip install Pillow==12.3.0
.venv/bin/python scripts/bake-planets.py
```

The script reads the four JPG maps in `public/planets` and writes three `.points.gz` files beside them. A fixed seed keeps the output reproducible. Keep `credits.txt` with the assets when reusing them; the maps come from Solar System Scope under CC BY 4.0. Earth colors are enhanced, and Jupiter's colors are remapped to violet. Rings and atmospheric points are generated by the script.

Each uncompressed file starts with `KPL1`, then a little-endian 32-bit point count. Each point takes 12 bytes:

| Field | Storage | Decoding |
| --- | --- | --- |
| x, y, z | Three signed 16-bit integers | Divide by 10,000 |
| red, green, blue | Three unsigned bytes | Divide by 255 |
| random seed | Unsigned 16-bit integer | Divide by 65,535 |
| layer | Unsigned byte | Divide by 10 |

The loader validates the header and record count before expanding the records into GPU attributes. On small screens it takes every other point. It accepts either gzip bytes or already-decompressed bytes because servers handle `.gz` files differently.

The JPGs are conversion inputs. A running page only fetches the compressed point files. If your site lives under a subpath, set the component's `assetBase` to the corresponding public URL.
